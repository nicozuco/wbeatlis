# ATLIS WEB

Este es el proyecto independiente de la web comercial de ATLIS.

- Todo el trabajo se realiza dentro de esta carpeta.
- No modificar, ejecutar, instalar dependencias ni arrancar servidores en la app vecina `AGENCIA IA`.
- La app solo se ha utilizado como fuente de los logotipos oficiales, copiados aquí.
- El sitio usa HTML, CSS y JavaScript con un servidor Node sin dependencias externas.
- La referencia editorial es `docs/brief-original.md`.
- No publicar automáticamente. Esta entrega es una revisión local.
- No inventar datos empresariales, testimonios, resultados, integraciones ni políticas legales.
- Mantener el formulario bloqueado hasta configurar el receptor y la información legal reales.
- No confirmar solicitudes sin confirmación explícita del receptor.
- No recopilar datos sanitarios, instalar analítica ni enviar datos a terceros sin la configuración y autorización correspondientes.
- Revisar `docs/PENDIENTES.md` antes de preparar una publicación.
- Comprobar `npm run check` y, cuando se cambie el servicio de envío, `npm test`.
