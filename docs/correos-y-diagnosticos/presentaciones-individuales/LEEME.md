# Presentaciones individuales

Cada ZIP contiene una sola presentación, sus datos y sus imágenes. Descomprimir y abrir index.html para revisión local, o publicar el contenido en un alojamiento estático para obtener un enlace compartible. No se han publicado ni enviado.

Los enlaces 127.0.0.1 de la conversación solo funcionan en este ordenador. Los textos de correo incluyen un espacio para sustituir por el enlace público después de publicarlo.

Los recorridos de citas son simulaciones; ninguna reserva modifica una agenda real.
